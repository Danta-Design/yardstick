# Feedback log

Every conversation with a real user goes here, including the ones that went
badly. This file is evidence for the resume bullet and raw material for the
roadmap — do not edit it after the fact.

## Template

```
### YYYY-MM-DD · <who / role>

- Context: what they are building, team size
- Tried: what they ran
- Worked: what was fine
- Broke: exact error or confusion, with the command
- Wanted: what they asked for next
- Action: issue link, or "not doing, because ..."
```

## What to ask (do not improvise)

1. What did you use before this? Why did you stop?
2. Show me the last time you changed a prompt — how did you know it was better?
3. If this tool disappeared tomorrow, what would you miss?
4. How long did setup take, honestly?

Write down the answers verbatim. Paraphrasing loses the signal.
